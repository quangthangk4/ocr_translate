Dịch theo cách của bạn

Ảnh bạn chọn được gửi trực tiếp đến dịch vụ dịch bằng API key của bạn.

Dịch và hiểu tạo cả phần học trong một lượt API; dùng nhiều token hơn. Mở phần giải thích đã lưu không gọi thêm API.
Kiểm tra kết nối dùng một lượt API với cấu hình đang nhập. Không tự gọi khi mở cài đặt.

Bắt đầu đọc truyện

Chọn OCR cục bộ để chỉ lấy chữ tiếng Anh, không cần API key. Bôi chọn chữ trong thẻ để dùng extension dịch của bạn. Với Gemini, thiết lập theo các bước dưới:

  1. Tạo API key từ Google AI Studio và chọn project ở gói Free.
  2. Lưu key và model bạn có quyền truy cập.
  3. Mở trang truyện, bấm biểu tượng extension hoặc Ctrl+Shift+Y.
  4. Khoanh vùng truyện hoặc chọn “Dịch khung nhìn”.

Hạn mức của Antigravity và Gemini trực tiếp là riêng biệt. Extension dừng khi chạm hạn mức, không tự đổi model. Nếu key thuộc project có billing, lượt API có thể tính phí.

Bản dịch đã lưu trên máy

Giữ văn bản, phần học và vị trí vùng ảnh qua các lần mở Brave. Không lưu ảnh chụp. Tối đa 500 thẻ hoặc 5 MB; đạt giới hạn thì dọn bản cũ nhất. API key và cài đặt được giữ nguyên khi xóa dữ liệu.

Dữ liệu gửi đến Gemini chịu chính sách của Google; gói Free có thể được dùng để cải thiện sản phẩm.
